City websites missing Open Graph tags

186 of 212 fully scanned U.S. city websites are missing Open Graph tags. The share in each state and every site listed, from ScanGov homepage scans.

  • Sites: 266
  • Last scan: 11/1/2026

Of the 212 fully scanned U.S. city sites we tested, 186 (88%) are missing Open Graph tags. Among states with at least 10 tested sites, California has the highest share (94%). Texas has the lowest (90%). Open Graph tags tell social networks, chat apps, and search engines which title, description, and image to show when someone shares a link to the page. Without them a shared link shows whatever the platform can guess, often nothing. A site fails if it fails any of these checks: Open Graph title, Open Graph description, Open Graph image, Open Graph URL, Open Graph type, and Open Graph site name.

About these checks

Open Graph tags tell social networks, chat apps, and search engines which title, description, and image to show when someone shares a link to the page. Without them a shared link shows whatever the platform can guess, often nothing. These usability checks test each part of that. The image alt text tag is not counted here: of the sites that set every other tag, most leave it out, so counting it would hide the difference between sites that set up Open Graph and sites that never did.

  • Open Graph title. The page has a title for social media previews. Shared links have no title on social media.
  • Open Graph description. The page has a description for social media previews. Shared links have no description on social media.
  • Open Graph image. The page has a preview image for social media cards. Shared links have no image on social media.
  • Open Graph URL. The page has a canonical URL for social media sharing. Shared links may point to wrong page.
  • Open Graph type. The page declares its content type for social media cards. Social media shows wrong content type.
  • Open Graph site name. The site has a name for social media and browser display. Site name missing in social media shares.

About this data

ScanGov scans the homepage of each county site on our county list. Scores come from the checks in the ScanGov standards. Sites were scanned between 9/25/2026 and 11/1/2026. Each site's report shows its own scan date. A site counts as fully scanned when its homepage loaded and sent us its page content. Averages, grade shares, failure rates, and ranks use fully scanned sites only. We could not fully scan 54 sites. They did not respond, blocked the scanner, or sent no page content. They appear in the table without grades, with their scan status, and are left out of every figure. Grades follow the ScanGov grade scale. Rank follows the ScanGov ranking method. The full dataset, with every county's raw results, is in the ScanGov data repository.
