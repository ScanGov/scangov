999 Request Denied

A non-standard code used by some sites to actively block automated or bot traffic. 156 websites return this status. See what it means and how to fix it.

Scan failed

We weren't able to scan your site.

Description

A non-standard code used by some sites to actively block automated or bot traffic.

Problem

The site is actively blocking automated tools, including this scanner, so its content can't be verified or indexed by anyone using similar tools.

Recommendation

Your site is blocking automated visitors on purpose, and that includes good bots. Ask whoever set that up to let good bots through. Learn more about what to allow.

Technical recommendation

Review bot-blocking rules to allow legitimate crawlers and monitoring services, or confirm this restriction on this URL is intentional. Allow the ScanGovBot user-agent, or allowlist 44.236.34.143.

Details

  • Label: Request Denied
  • Type: inaccessible
  • Code: 999

ScanGovBot

Our scanner identifies itself as ScanGovBot. If your site uses a firewall or bot protection, allow it through: https://scangov.com/bot

Examples

Allow ScanGovBot in a firewall or bot protection

User-agent: Mozilla/5.0 (compatible; ScanGovBot/1.0; +https://scangov.com/bot)
IP address: 44.236.34.143

Allow ScanGovBot in robots.txt

User-agent: ScanGovBot
Allow: /
