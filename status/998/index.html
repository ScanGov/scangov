Scan skipped

We didn't scan your site because its robots.txt asked us not to.

Description

A non-standard code ScanGov uses when a site's robots.txt asks ScanGovBot not to crawl it. The site itself loaded normally.

Problem

Your robots.txt disallows ScanGovBot (or all crawlers). ScanGov honours that request and does not scan the site, so its content can't be verified or shown here until the file allows the bot.

Recommendation

If you want ScanGov to scan your site, ask whoever manages your robots.txt to allow good bots. Learn more about what to allow.

Technical recommendation

Add a group to /robots.txt that allows ScanGovBot: "User-agent: ScanGovBot" followed by "Allow: /". A blanket "User-agent: *" / "Disallow: /" rule blocks ScanGovBot unless a more specific ScanGovBot group allows it.
