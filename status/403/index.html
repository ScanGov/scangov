403 Forbidden

The server understood the request but refused to fulfill it. The client does not have permission to access this resource. 232 websites return this status. See what it means and how to fix it.

Scan failed

We weren't able to scan your site.

Description

The server understood the request but refused to fulfill it. The client does not have permission to access this resource.

Problem

The server actively blocked access, which may indicate misconfigured permissions, a firewall rule, or a bot-blocking tool that's also blocking legitimate crawlers (like ScanGovBot).

Recommendation

Something on your site is turning visitors away, and it's catching good bots too. Ask whoever manages your security settings to let good bots through. Learn more about what to allow.

Technical recommendation

Review server/firewall rules and any bot-protection service (e.g. a WAF or Cloudflare) to confirm search engines and monitoring tools aren't being blocked unintentionally. Allow the ScanGovBot user-agent, or allowlist 44.236.34.143.

Details

  • Label: Forbidden
  • Type: inaccessible
  • Code: 403

ScanGovBot

Our scanner identifies itself as ScanGovBot. If your site uses a firewall or bot protection, allow it through: https://scangov.com/bot

Examples

Allow ScanGovBot in a firewall or bot protection

User-agent: Mozilla/5.0 (compatible; ScanGovBot/1.0; +https://scangov.com/bot)
IP address: 44.236.34.143
