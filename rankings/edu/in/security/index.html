What each check means

  • X-Content-Type-Options. The site tells browsers not to guess the type of files it serves. Browsers might run dangerous files by mistake.
  • Errors in the console. The page loads without JavaScript or network errors. Site may have hidden bugs that break features.
  • Security.txt. The site has a security.txt file so researchers know how to report issues. Security researchers cannot report problems to you.

About security

Why it's important

Strong defenses prevent hackers from stealing personal information and other confidential data.

Guidance

What we use to grade security:

  • CISA Website Security

  • U.S. Federal Website Standards

Standards

  • HTTP Strict Transport Security (HSTS)

  • X-Content-Type-Options
  • Errors in the console

About this data

ScanGov scans the homepage of each college and university site on our higher education list. Scores come from the checks in the ScanGov standards. Sites were scanned between 10/27/2026 and 11/8/2026. Each site's report shows its own scan date. A site counts as fully scanned when its homepage loaded and sent us its page content. Averages, grade shares, failure rates, and ranks use fully scanned sites only. We could not fully scan 1 sites. They did not respond, blocked the scanner, or sent no page content. They appear in the table without grades, with their scan status, and are left out of every figure. Grades follow the ScanGov grade scale. Rank follows the ScanGov ranking method. The full dataset, with every county's raw results, is in the ScanGov data repository.
