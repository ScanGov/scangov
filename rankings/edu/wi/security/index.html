What each check means

  • X-Content-Type-Options. The site tells browsers not to guess the type of files it serves. Browsers might run dangerous files by mistake.
  • Errors in the console. The page loads without JavaScript or network errors. Site may have hidden bugs that break features.
  • Security.txt. The site has a security.txt file so researchers know how to report issues. Security researchers cannot report problems to you.

About this data

Project ScanGov scans the homepage of each college and university site on our higher education list. Scores come from the checks in the ScanGov standards. Sites were scanned between 10/27/2026 and 11/8/2026. Each site's report shows its own scan date. A site counts as scanned when its homepage loaded and sent us its page content. Averages, grade shares, failure rates, and ranks use scanned sites only. What the security checks measure, and why they matter, is on the security page. Grades follow the ScanGov grade scale. Rank follows the ScanGov ranking method. The full dataset, with every county's raw results, is in the ScanGov data repository.
