What each check means

  • Open Graph image alt. The social media preview image has alt text for screen readers. Screen readers cannot describe shared images.
  • First Contentful Paint (FCP). The page starts displaying content within 1.8 seconds. Users see blank screen and think site is broken.
  • Time to First Byte (TTFB). The server sends the first byte of content within 0.8 seconds. Slow server delays everything on your page.
  • Open Graph image. The page has a preview image for social media cards. Shared links have no image on social media.
  • Open Graph site name. The site has a name for social media and browser display. Site name missing in social media shares.

About this data

ScanGov scans the homepage of each college and university site on our higher education list. Scores come from the checks in the ScanGov standards. Sites were scanned between 10/28/2026 and 11/8/2026. Each site's report shows its own scan date. A site counts as fully scanned when its homepage loaded and sent us its page content. Averages, grade shares, failure rates, and ranks use fully scanned sites only. Grades follow the ScanGov grade scale. Rank follows the ScanGov ranking method. The full dataset, with every county's raw results, is in the ScanGov data repository.
