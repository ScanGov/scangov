What each check means

  • Errors in the console. The page loads without JavaScript or network errors. Site may have hidden bugs that break features.
  • Security.txt. The site has a security.txt file so researchers know how to report issues. Security researchers cannot report problems to you.
  • Sponsored top-level domain (sTLD). The site uses a government-issued domain (.gov, .edu, or .mil). People cannot tell if your site is real government.
  • X-Content-Type-Options. The site tells browsers not to guess the type of files it serves. Browsers might run dangerous files by mistake.

About security

Why it's important

Strong defenses prevent hackers from stealing personal information and other confidential data.

Guidance

About this data

ScanGov scans the homepage of each county government site on our county list in Iowa. Scores come from the checks listed on standards.scangov.org. Sites were scanned between 7/19/2026 and 9/18/2026; each site's report shows its own scan date. A site counts as responding when its homepage returned successfully. Averages, grade shares, and failure rates use responding sites only. 7 of the 87 responding sites did not return page content to the scanner, so content checks (text, Open Graph tags, readability) were not scored. They are included in every figure and marked "partial scan" in the table. Grades follow the ScanGov grade scale, and rank follows the ScanGov ranking method. The full dataset, including every county's raw results, is published in the ScanGov data repository.
