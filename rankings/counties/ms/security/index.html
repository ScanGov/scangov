What each check means

  • Sponsored top-level domain (sTLD). The site uses a government-issued domain (.gov, .edu, or .mil). People cannot tell if your site is real government.
  • Errors in the console. The page loads without JavaScript or network errors. Site may have hidden bugs that break features.
  • Hypertext Transfer Protocol Secure (HTTPS). The site uses HTTPS to encrypt data between the server and users. Hackers can see and steal personal information.
  • Security.txt. The site has a security.txt file so researchers know how to report issues. Security researchers cannot report problems to you.

About this data

ScanGov scans the homepage of each county government site on our county list in Mississippi. Scores come from the checks listed on standards.scangov.org. Sites were scanned between 7/18/2026 and 9/18/2026; each site's report shows its own scan date. A site counts as fully scanned when its homepage returned successfully and sent the scanner its page content. Averages, grade shares, failure rates, and ranks use fully scanned sites only. We weren't able to fully scan 6 sites because they did not respond, blocked the scanner, or returned no page content. They appear in the table without grades, each with its scan status, and are left out of every figure. Grades follow the ScanGov grade scale, and rank follows the ScanGov ranking method. The full dataset, including every county's raw results, is published in the ScanGov data repository.
