What each check means

  • Document has a main landmark. The page has exactly one main content area so screen readers can navigate to it. Screen reader users cannot skip directly to main content.
  • Td elements in a large table have one or more table headers. Each cell in a large table is linked to a header so screen readers can navigate it. Screen reader users cannot understand data in large tables.
  • Links have a discernible name. Links have unique, descriptive text so users know where they go. Screen reader users cannot identify or interact with elements.
  • Elements with an ARIA [role] that require children to contain a specific [role] have all required children. Interactive groups contain all the child elements they need to work correctly. Screen readers cannot navigate grouped elements like menus or lists.
  • [aria-hidden="true"] elements do not contain focusable descendents. Interactive elements are not hidden from screen reader users. Keyboard users can focus elements that screen readers cannot announce.

About this data

Project ScanGov scans the homepage of each county site on our county list in Oklahoma. Scores come from the checks in the ScanGov standards. Sites were scanned between 10/27/2026 and 11/7/2026. Each site's report shows its own scan date. A site counts as scanned when its homepage loaded and sent us its page content. Averages, grade shares, failure rates, and ranks use scanned sites only. We could not scan 4 sites. They did not respond, blocked the scanner, or sent no page content. They appear in the table without grades, with their scan status, and are left out of every figure. What the accessibility checks measure, and why they matter, is on the accessibility page. Grades follow the ScanGov grade scale. Rank follows the ScanGov ranking method. The full dataset, with every county's raw results, is in the ScanGov data repository.
