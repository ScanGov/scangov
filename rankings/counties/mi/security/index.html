What each check means

  • Sponsored top-level domain (sTLD). The site uses a government-issued domain (.gov, .edu, or .mil). People cannot tell if your site is real government.
  • Errors in the console. The page loads without JavaScript or network errors. Site may have hidden bugs that break features.
  • Security.txt. The site has a security.txt file so researchers know how to report issues. Security researchers cannot report problems to you.
  • X-Content-Type-Options. The site tells browsers not to guess the type of files it serves. Browsers might run dangerous files by mistake.

About security

Secure your site and protect users with proper security practices.

Why it's important

Strong defenses prevent hackers from stealing personal information and other confidential data.

Risks

  • Hackers can steal private information from your site.

Guidance

What we use to grade security:

  • CISA Website Security
  • 21st Century Integrated Digital Experience Act (IDEA)
  • CISA Cybersecurity Performance Goals
  • RFC 9116
  • OWASP Top 10
  • U.S. Federal Website Standards

Standards

  • Content security policy (CSP)
  • HTTP Strict Transport Security (HSTS)
  • security.txt
  • X-Content-Type-Options
  • Errors in the console
  • Clickjacking mitigation
  • Paste preventing inputs
  • Hypertext Transfer Protocol Secure (HTTPS)

About this data

ScanGov scans the homepage of each county government site on our county list in Michigan. Scores come from the checks listed on standards.scangov.org. Sites were scanned between 7/19/2026 and 9/18/2026; each site's report shows its own scan date. A site counts as fully scanned when its homepage returned successfully and sent the scanner its page content. Averages, grade shares, failure rates, and ranks use fully scanned sites only. We weren't able to fully scan 13 sites because they did not respond, blocked the scanner, or returned no page content. They appear in the table without grades, each with its scan status, and are left out of every figure. Grades follow the ScanGov grade scale, and rank follows the ScanGov ranking method. The full dataset, including every county's raw results, is published in the ScanGov data repository.
