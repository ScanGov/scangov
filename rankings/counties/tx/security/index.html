What each check means

  • Sponsored top-level domain (sTLD). The site uses a government-issued domain (.gov, .edu, or .mil). People cannot tell if your site is real government.
  • Errors in the console. The page loads without JavaScript or network errors. Site may have hidden bugs that break features.
  • X-Content-Type-Options. The site tells browsers not to guess the type of files it serves. Browsers might run dangerous files by mistake.
  • Security.txt. The site has a security.txt file so researchers know how to report issues. Security researchers cannot report problems to you.
  • Hypertext Transfer Protocol Secure (HTTPS). The site uses HTTPS to encrypt data between the server and users. Hackers can see and steal personal information.

About this data

ScanGov scans the homepage of each county site on our county list in Texas. Scores come from the checks in the ScanGov standards. Sites were scanned between 9/30/2026 and 11/5/2026. Each site's report shows its own scan date. A site counts as fully scanned when its homepage loaded and sent us its page content. Averages, grade shares, failure rates, and ranks use fully scanned sites only. We could not fully scan 18 sites. They did not respond, blocked the scanner, or sent no page content. They appear in the table without grades, with their scan status, and are left out of every figure. Grades follow the ScanGov grade scale. Rank follows the ScanGov ranking method. The full dataset, with every county's raw results, is in the ScanGov data repository.
