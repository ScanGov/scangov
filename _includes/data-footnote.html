About this data

ScanGov scans the homepage of each county government site on our county list{% if footnoteScope %} {{ footnoteScope }}{% endif %}. Scores come from the checks listed on standards.scangov.org. {% if footnoteScanWindow %}Sites were scanned between {{ footnoteScanWindow.from | standardFormatDate }} and {{ footnoteScanWindow.to | standardFormatDate }}; each site's report shows its own scan date.{% else %}The last scan finished on {{ updates }}.{% endif %} A site counts as responding when its homepage returned successfully. Averages, grade shares, and failure rates use responding sites only. {% if footnotePartialCount %}{{ footnotePartialCount }} of the {{ footnoteRespondingCount }} responding sites did not return page content to the scanner, so content checks (text, Open Graph tags, readability) were not scored. They are included in every figure and marked "partial scan" in the table.{% endif %} Grades follow the ScanGov grade scale, and rank follows the ScanGov ranking method. The full dataset, including every county's raw results, is published in the ScanGov data repository.
